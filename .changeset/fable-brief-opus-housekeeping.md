The brief is now written by Claude Fable 5.1 by default (`claude-fable-5-1`), and the housekeeping passes (living context, memory, fact check and auto-close) run on Claude Opus 5.5 instead of Haiku 5.5. Every request on a model that supports it, housekeeping included, now opts into the server-side refusal fallback, so a pass a safety classifier declines is retried instead of skipped. A busy household's monthly cost rises to roughly $55, about half of it housekeeping. The README, setup guide and example config now show current costs for all three brief models.
